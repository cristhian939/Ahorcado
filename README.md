# Juego del Ahorcado - Proyecto 

Este repositorio contiene el código fuente y la documentación para el desarrollo del clásico "Juego del Ahorcado".

## Descripción del Proyecto

El objetivo principal de este proyecto es implementar la lógica de un juego interactivo por consola, aplicando conceptos fundamentales de programación estructurada. El desarrollo hace énfasis en la planificación previa mediante diagramas lógicos antes de la codificación.

## Funcionalidades Principales

* Selección aleatoria de palabras desde un banco de datos.
* Interfaz interactiva por consola.
* Validaciones robustas de entrada de usuario (letras repetidas, caracteres inválidos).
* **Innovación:** Sistema de pistas estratégicas que penalizan al jugador restando vidas a cambio de una ayuda.
* Control estricto de los estados de victoria y derrota.

## Tecnologías y Herramientas

* **Lenguaje:** Python 3.14.6
* **Entorno de Desarrollo:** Visual Studio Code
* **Control de Versiones:** GitHub
* **Diagramación:** Lucidchart

## Estructura del Repositorio

El proyecto sigue una estructura organizada para separar la lógica de la documentación:

* `/docs`: Contiene el informe académico completo (Marco Teórico, Metodología) y el Diagrama de Flujo lógico.
* `/src`: Contiene los scripts y el código fuente del juego.
* `/data`: Almacena el banco de palabras utilizado por el sistema.
